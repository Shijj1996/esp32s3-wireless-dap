# 在另一台电脑上使用这套无线 DAP

> 前提：ESP32-S3 盒子已经烧好固件（本仓库的 `wireless_esp_dap.bin`）。
> 换电脑**不需要重新烧盒子**，只需要配电脑这一侧。

---

## 0. 最简三步

```powershell
# 1. 开 Windows 移动热点：SSID = ESP32-DAP / 密码 = 12345678 / 2.4 GHz
# 2. 插上盒子（USB 供电），等 2 秒

# 3. 挂载
& 'C:\Program Files\USBip\usbip.exe' attach -r 192.168.137.50 -b 1-1 --receive-mode low-latency
```

成功即出现 `successfully attached to port 1`，然后用 §5 烧录 STM32。

---

## 1. 这台电脑需要什么

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64 |
| usbip 客户端 | **usbip-win2 0.9.8.1**（唯一推荐版本） |
| Wi-Fi | 支持 2.4 GHz 且支持「移动热点」 |
| 调试用 | STM32CubeIDE（用于取 OpenOCD + GDB）|
| 权限 | 安装驱动需要管理员；日常 attach 不需要 |

---

## 2. 安装 usbip-win2

### 2.1 下载

https://github.com/vadimgrn/usbip-win2/releases/download/v.0.9.8.1/USBip-0.9.8.1-x64.exe

### 2.2 为什么必须是 0.9.8.1

- 这一版是 **WHCP 签名**，Secure Boot 开着的机器能直接装
- 旧的 0.3.x（cezanne 分支）是自签名驱动，Secure Boot 下会被拒绝加载

### 2.3 安装

右键管理员运行安装包，默认选项即可。装完确认：

```powershell
& 'C:\Program Files\USBip\usbip.exe' --version
```

**装完必须重启一次**（驱动加载）。

---

## 3. 开移动热点

`设置 → 网络和 Internet → 移动热点`

| 字段 | 值 |
|---|---|
| 名称（SSID） | `ESP32-DAP` |
| 密码 | `12345678` |
| 网络频段 | **2.4 GHz** |
| 共享来源 | 你正在用的网络（Wi-Fi 或以太网） |

> ⚠️ ESP32-S3 **只有 2.4 GHz**，选 5 GHz 盒子扫不到。
> ⚠️ Windows 的 ICS 热点地址固定是 `192.168.137.1`，盒子固定 `192.168.137.50`，
> 所以**不能用手机热点**（手机热点一般是 `192.168.43.x`，盒子会连不上）。

### 怎么确认热点参数（可选）

```powershell
.\tools\get-hotspot-config.ps1
```

## 4. 挂载设备

> **想一条命令直接到能用（检测 + 挂载 + 起 OpenOCD）**，跳到 §4.6。
> 下面 4.1~4.5 是手动拆解，用来排查问题。

### 4.1 确认盒子在线

```powershell
Test-NetConnection 192.168.137.50 -Port 3240 -InformationLevel Quiet
```

`True` 才算通。不通 → 盒子没上电 / 没连上热点 / 热点没开。

### 4.2 查看远端导出的设备

```powershell
& 'C:\Program Files\USBip\usbip.exe' list -r 192.168.137.50
```

期望：

```
    1-1    : Keil Software, Inc. : unknown product (c251:f00a)
```

### 4.3 挂载

```powershell
& 'C:\Program Files\USBip\usbip.exe' attach -r 192.168.137.50 -b 1-1 --receive-mode low-latency
```

> **`--receive-mode low-latency` 必须加**
> 默认的 `zero-copy` 模式会串行化 URB，导致 CMSIS-DAP 写-读死锁
> （`busy command USB transfer` / `CMD_INFO failed`）。

### 4.4 验证

```powershell
& 'C:\Program Files\USBip\usbip.exe' port
Get-PnpDevice | Where-Object { $_.InstanceId -match 'VID_C251' } |
    Select-Object Status, FriendlyName
```

期望：

```
Port 01: device in use at High Speed(480Mbps)

Status  FriendlyName
OK      Wireless ESP CMSIS-DAP
```

### 4.5 驱动不用手动装

设备用的是 **WinUSB**，靠 WCID（MS OS 2.0 描述符）由盒子自己声明，
Windows 10/11 会自动绑定 `winusb.inf`。**不需要 Zadig、不需要 inf 文件。**

### 4.6 一条命令：检测 + 挂载 + 起 OpenOCD

`serve` 是脚本的**默认模式**，所以直接跑：

```powershell
.\tools\stm32cubeide-dap.ps1 -Target stm32f1x -Speed 300
```

它自动完成：

1. **检测** `VID_C251` 设备节点、`IP:3240`、`usbip list`、`usbip port`
2. **挂载**（未挂载时执行 `attach --receive-mode low-latency`，等最多 15 秒）
3. **防重复**：3333/4444 被占用就直接报错退出
4. **启动 OpenOCD**：GDB `3333` / telnet `4444` / tcl `6666`

看到这个横幅就表示可以连 CubeIDE 了：

```
==================================================
  无线 DAP 已就绪
--------------------------------------------------
  设备   : Wireless ESP CMSIS-DAP
  GDB    : localhost:3333
  Telnet : localhost:4444
  目标   : stm32f1x @ 300 kHz
  退出   : Ctrl+C
==================================================
```

## 5. 烧录 STM32 固件

### 5.1 拷贝脚本

把仓库里的 `tools\` 整个目录拷到新电脑（任意位置）。

### 5.2 确认脚本里的路径

打开 `tools\stm32cubeide-dap.ps1`，顶部 4 个参数按新电脑实际情况改：

```powershell
[string]$HostIp   = '192.168.137.50'                                    # 一般不用改
[string]$BusId    = '1-1'                                               # 一般不用改
[string]$CubeRoot = 'D:\STM32CubeIDE_1.19.0\STM32CubeIDE'               # ★ 改成新电脑的安装路径
[string]$UsbipCli = 'C:\Program Files\USBip\usbip.exe'                  # 一般不用改
```

脚本会自动在 `$CubeRoot\plugins` 下找 `openocd.exe`、`st_scripts`、`arm-none-eabi-gdb.exe`。

### 5.3 烧录

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\tools\stm32cubeide-dap.ps1 `
  -Mode flash -Target stm32f1x -Speed 300 `
  -Elf 'D:\your_project\Debug\your_app.elf'
```

成功输出：

```
wrote 19016 bytes ... in 6.44s (2.883 KiB/s)
verified 19016 bytes in 1.49s (12.429 KiB/s)
[+] 烧录完成
```

### 5.4 支持的格式与常用选项

```powershell
# ELF / HEX / BIN 都支持
.\tools\stm32cubeide-dap.ps1 -Mode flash -Image app.elf
.\tools\stm32cubeide-dap.ps1 -Mode flash -Image app.hex
.\tools\stm32cubeide-dap.ps1 -Mode flash -Image app.bin -Address 0x08000000

# 烧完立即运行
.\tools\stm32cubeide-dap.ps1 -Mode flash -Image app.elf -Run

# 先整片擦除 / 跳过校验
.\tools\stm32cubeide-dap.ps1 -Mode flash -Image app.elf -ChipErase
.\tools\stm32cubeide-dap.ps1 -Mode flash -Image app.elf -NoVerify

# 整片擦除
.\tools\stm32cubeide-dap.ps1 -Mode erase

# 整片回读成 bin（容量自动探测）
.\tools\stm32cubeide-dap.ps1 -Mode dump -DumpFile .\readback.bin

# 只打印命令，不碰硬件
.\tools\stm32cubeide-dap.ps1 -Mode flash -Image app.bin -Address 0x08000000 -DryRun
```

> `-Elf` 是 `-Image` 的旧别名，老命令仍然能用。

### 5.5 如果新电脑没装 CubeIDE

脚本依赖 CubeIDE 自带的 OpenOCD 和 GDB。两个选择：

- **装一个 STM32CubeIDE**（最省事，脚本能自动找到）
- 或者自己下载 OpenOCD + `arm-none-eabi` 工具链，然后改 `$CubeRoot` 相关逻辑或直接用 §6 的原始命令

## 6. 不用脚本的原始命令

```powershell
$ocd     = '<CubeIDE>\plugins\…openocd…\tools\bin\openocd.exe'
$scripts = '<CubeIDE>\plugins\…openocd…\debug.openocd…\resources\openocd\st_scripts'

# 起 GDB 服务（GDB 连 localhost:3333）
& $ocd -s $scripts `
   -f "interface/cmsis-dap.cfg" `
   -c "cmsis-dap vid_pid 0xc251 0xf00a" `
   -f "target/stm32f1x.cfg" `
   -c "adapter speed 300" -c "gdb_port 3333"

# 一次性烧录
& $ocd -s $scripts `
   -f "interface/cmsis-dap.cfg" `
   -c "cmsis-dap vid_pid 0xc251 0xf00a" `
   -f "target/stm32f1x.cfg" -c "adapter speed 300" `
   -c "init; halt" `
   -c "flash write_image erase {你的.elf}" `
   -c "verify_image {你的.elf}" `
   -c "reset halt" -c "shutdown"
```

> ❌ 不要用 `program`：它内部的 `reset init` 在这条链路上会让目标失联。

## 7. 新电脑排查清单

| 现象 | 原因 | 处理 |
|---|---|---|
| `usbip list` 超时 | 盒子没连上热点 / 热点没开 | 看盒子串口日志、重开热点 |
| `usbip list` 正常但 `attach` 卡住 | 驱动端口僵尸 | 重启电脑，或跑 `tools\reset-usbip.ps1`（管理员） |
| `attach` 成功但 OpenOCD 报 `CMD_INFO failed` | 忘了 `--receive-mode low-latency` | detach 后重挂 |
| `cannot read IDR`，`SWDIO/TMS = 0` | 目标没供电 / GND 没接 | 量电压、查地线 |
| `cannot read IDR`，`SWDIO/TMS = 1` | 速率过高 或 走了 reset-init | 降到 300 kHz；改用 `flash write_image` |
| 设备管理器里没有 `Wireless ESP CMSIS-DAP` | attach 没成功 / 驱动没绑定 | 看 `usbip port`，重挂；确认不是旧版 usbip CLI |
| PowerShell 报「禁止运行脚本」 | 执行策略 | 命令前加 `-ExecutionPolicy Bypass` |

### 7.1 检查是不是用错了 usbip CLI

机器上可能同时存在多个 `usbip.exe`。旧版（0.3.x）对应的驱动已经不存在，会报奇怪的错。

**统一用这个路径**：

```
C:\Program Files\USBip\usbip.exe
```

```powershell
& 'C:\Program Files\USBip\usbip.exe' --version
```

## 8. 换电脑后盒子需要改配置吗

| 场景 | 要不要重新烧盒子 |
|---|---|
| 新电脑同样开热点 `ESP32-DAP` / `12345678` | ❌ 不用 |
| 想改热点名或密码 | ✅ 改 `main/wifi_configuration.h` 的 `wifi_list[]` 后重烧 |
| 新电脑用手机热点（`192.168.43.x`） | ✅ 必须改，静态 IP 也要改成对应网段，或把 `USE_STATIC_IP` 设为 0 |
| 新电脑用有线网共享热点 | ❌ 不用（ICS 仍是 `192.168.137.1`） |

`main/wifi_configuration.h` 关键项：

```c
#define USE_SOFTAP     0
#define USE_STATIC_IP  1
#define DAP_IP_ADDRESS 192, 168, 137, 50
#define DAP_IP_GATEWAY 192, 168, 137, 1
#define DAP_IP_NETMASK 255, 255, 255, 0

wifi_list[] = { {"ESP32-DAP", "12345678"} }
```

改完：

```powershell
.\build.ps1 build
.\build.ps1 -p COMx flash
```

## 9. 硬件接线（每台电脑都一样）

| 信号 | ESP32-S3 盒子 | STM32 目标 |
|---|---|---|
| SWDIO | GPIO11 | SWDIO / PA13 |
| SWCLK | GPIO12 | SWCLK / PA14 |
| GND | GND | GND（**必接**） |
| nRESET（可选） | GPIO13 | NRST |

> ⚠️ 接电前用万用表确认 3V3 / GND，F103 最小系统板这两个丝印相邻，接反会烧芯片。
> 推荐目标板自己用 USB 供电，只连 SWDIO / SWCLK / GND 三根。
